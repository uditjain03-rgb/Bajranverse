# Monster Mayhem Run

`www/` is the complete web game (`index.html` + `game.js` bundle, images, fonts), taken from the released
**MonsterMayhemRun-v15.0.apk** that the owner provided. It is the built game, not the original editable source: the
original project was made outside this repository. The APK itself is kept locally in `deliver/monster-mayhem-run/`
(not committed). Its studio logo and title music were reused by Rocky's Pirate Army.

To play it locally: `cd www && python3 -m http.server` and open http://localhost:8000.
